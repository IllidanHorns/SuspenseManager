# SuspenseManager

Разработка информационной системы обработки и управления стриминговыми данными цифровых музыкальных платформ (на примере ООО «Убо Софт»).

## Тестовые данные

Файл [`TestData/test_report.xlsx`](TestData/test_report.xlsx) — пример отчёта стриминговой площадки для загрузки через раздел **Загрузка отчётов**.
