# Справочник: идентификаторы музыкальных продуктов и реквизиты компаний

Используется операторами и сотрудниками бэк-офиса при работе с карточками суспенсов, группами и каталогом.

---

## ISRC — International Standard Recording Code
**Международный стандартный код записи**

Уникальный идентификатор, присваиваемый каждой отдельной записи (треку). Устанавливается организацией IFPI. Именно по ISRC стриминговые платформы (Яндекс.Музыка, Apple Music, Spotify и др.) идентифицируют релиз в своих отчётах.

### Структура
```
CC - XXX - YY - NNNNN
│     │    │      └── Порядковый номер записи (5 цифр)
│     │    └───────── Год регистрации (2 цифры)
│     └────────────── Код правообладателя (3 буквенно-цифровых символа)
└──────────────────── Код страны (2 заглавные буквы, ISO 3166-1)
```

### Правила формата
- Длина: **12 символов** без дефисов, **15 символов** с дефисами.
- Дефисы-разделители **необязательны**.
- Код страны — только буквы (латиница), остальные части — буквы и цифры.
- Пример без дефисов: `RUS1Z2400001`
- Пример с дефисами: `RU-S1Z-24-00001`

### Как использовать в системе
- ISRC — первичный ключ поиска продукта в каталоге при валидации суспенса.
- Если ISRC найден → продукт считается идентифицированным (переходим к проверке прав).
- Если ISRC в отчёте отсутствует или не найден → поиск по баркоду, затем по названию и исполнителю.

## Barcode — Штрихкод продукта (альбома/сборника)
**Международный код товара**

Баркод идентифицирует физический или цифровой релиз (альбом, EP, сингл) целиком. В отличие от ISRC, присваивается не треку, а продукту. Используется как **резервный идентификатор** при поиске в каталоге, если ISRC не дал результата.

### Поддерживаемые форматы

| Стандарт | Цифр | Применение |
|----------|------|------------|
| EAN-8    | 8    | Малая упаковка, короткие релизы |
| UPC-A    | 12   | Американский рынок, физические носители |
| EAN-13   | 13   | Международный стандарт, CD/LP/цифровые релизы |

### Правила формата
- Только **цифры** (0–9), без букв, пробелов и дефисов.
- Длина: строго **8, 12 или 13** цифр.
- Примеры: `12345678` (EAN-8), `012345678905` (UPC-A), `4607031750249` (EAN-13).

### Как использовать в системе
- Баркод — вторичный ключ поиска продукта (применяется, если ISRC не совпал).
- Один и тот же баркод может присутствовать на нескольких треках одного альбома — это нормально.

## ИНН — Идентификационный Номер Налогоплательщика

Российский налоговый идентификатор, который присваивается ФНС. Используется в карточках компаний-правообладателей, дистрибьюторов и платформ.

### Правила формата
- Только **цифры** (0–9).
- **10 цифр** — для юридических лиц и индивидуальных предпринимателей.
- **12 цифр** — для физических лиц.
- Примеры: `7707083893` (Сбербанк, ЮЛ), `500100732259` (физ. лицо).

### Как использовать в системе
- Заполняется в справочнике компаний (раздел «Каталог → Компании»).
- Используется для идентификации правообладателя при сверке документов.

---

## БИК — Банковский Идентификационный Код

Российский идентификатор банка, присваиваемый Центральным Банком России. Используется в банковских реквизитах компаний.

### Правила формата
- Только **цифры** (0–9).
- Ровно **9 цифр**.
- Первые две цифры — код страны (для России: `04`).
- Следующие две — код региона.
- Последние три — номер расчётно-кассового центра или банка.
- Пример: `044525225` (Сбербанк, Москва).

### Как использовать в системе
- Заполняется в справочнике компаний вместе с ИНН и наименованием банка.
- Необходим для формирования платёжных документов при распределении роялти.
